# ІПЗ Лабораторна робота №1 — Варіант 9 (Комунальні показники)

**Виконав:** студент групи КІ-301 Іроденко Р.І.  
**Тема:** UML діаграми варіантів використання та UML діаграми активності.

## Опис проєкту
Репозиторій містить UML-моделі (2 Use Case Diagrams та 6 Activity Diagrams) для системи обліку комунальних показників (Варіант 9).  
Усі діаграми спроектовані за допомогою інструменту PlantUML.

## Структура репозиторію
- `README.md` — опис проєкту та інструкція.
- `diagrams/` — вихідні `.puml` файли з PlantUML-кодом кожної з 8 діаграм:
  - `usecase-client.puml` — Use Case клієнтської частини
  - `usecase-server.puml` — Use Case серверної частини
  - `activity-init.puml` — Активність ініціалізації клієнта
  - `activity-results.puml` — Активність виводу результатів
  - `activity-file-check.puml` — Перевірка файлової системи
  - `activity-fromcsv.puml` — Парсинг CSV та створення об'єкта
  - `activity-process.puml` — Цикл обробки та агрегації
  - `activity-report-gen.puml` — Формування звіту

## Як відрендерити діаграми
Скопіюйте вміст будь-якого `.puml` файла та вставте його у [PlantUML Online Server](http://www.plantuml.com/plantuml/uml/).
